# Buyer Cockpit - preview

Public **preview build** of Buyer Cockpit, a replenishment assistance module for the
Buying History system. Published so the demo can be opened from a link with nothing running.

- **Illustrative data only.** No real prices, stock, suppliers or rebates.
- **No backend.** Everything is compiled into a single self-contained page.
- **One-tap sign-in** - pick a buyer, no password.
- The tool never writes to Buying History or the PO system; its output is an email.

Source is kept privately and is not published here.
